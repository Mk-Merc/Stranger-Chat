# Stranger-Chat
An Android app that connects users with random strangers for anonymous real-time text conversations.

## Demo

[Stranger Chat Demo](https://www.youtube.com/watch?v=LP6Y3lVGOO4)

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes. See deployment for notes on how to deploy the project on a live system.

### Prerequisites

* Node.js
* MongoDB
* Android Studio (Android SDK tools and emulator)
* Expo Go (For testing the application on a physical Android device)
* ngrok (For exposing the locally hosted backend server through a public URL)

### Installation

1. Clone the repo

2. Setup the backend

```
cd backend
npm install
```

3. Configure the backend environment variables

Create a .env file and provide the required MongoDB connection string

4. Start the backend server

```
npm run dev
```

5. Setup the frontend

```
cd frontend
npm install
```

6. Start the frontend

```
npx expo start
```

## Deployment

### Expo Go App

1. Open Expo Go App

The frontend development server URL will automatically appear after starting the frontend. If it does not, scan the QR code displayed in the terminal to connect to the application.

### Android APK Generation 

1. Generate the Android project

```
npx expo prebuild --platform android
```

2. Configure Gradle to use JDK 17

During Android builds, a Gradle compatibility error occurred with the system's default Java version. To resolve this Gradle was explicitly configured to use JDK 17.

Open gradle.properties and add:

```
org.gradle.java.home=C:/Program Files/Java/jdk-17
```

3. Configure CMake 

Force Gradle to use CMake 3.31.6 to fix the Windows long path (Ninja mkdir) build error.

Create a file named local.properties and add:
 
```
cmake.dir=C:/Users/YOUR_USERNAME/AppData/Local/Android/Sdk/cmake/3.31.6
```

4. Generate debug build

```
npx expo run:android --device
```

Note: The generated APK contains the Android application, but not the Ollama models or backend server. The application can still be used and its source files can be modified. However, if new libraries or native dependencies are added, the Android project must be regenerated and the APK rebuilt for those changes to be included.

### Tunnel Method

Tunneling allows the application to communicate with the locally hosted frontend development server and/or backend server over the internet.

1. Frontend Tunnel (Expo)

Log in to your Expo account:

```
npx eas-cli login
```

Start the Expo development server using tunnel mode:

```
npx expo start --tunnel
```

2. Backend Tunnel (ngrok)

Open the ngrok command prompt

Start a tunnel by specifying the port used by the backend server:

```
ngrok http YOUR_BACKEND_PORT
```

Copy the HTTPS forwarding URL generated by ngrok

Configure the frontend to use this public URL as its backend API endpoint

Note: For a standalone APK, the Expo frontend development-server tunnel is not required. Only the backend ngrok tunnel is needed for remote communication with the locally hosted backend.

## Features

* Anonymous Matchmaking: Randomly pairs users with other available users for anonymous conversations.
* Real-Time Messaging: Enables instant message exchange through Socket.IO.
* Inactivity Timeout: Automatically ends inactive chats after 60 seconds.
* Chat Termination Notifications: Displays a modal when a chat ends due to timeout, leaving, or disconnection.
* Permanent Blocking: Allows users to permanently block other users, preventing them from being matched again.
* Profanity Filtering: Censors inappropriate language using the bad-words library on both the frontend and backend.
